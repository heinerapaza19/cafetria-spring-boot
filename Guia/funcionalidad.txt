1. Cliente

A la izquierda están los clientes, que pueden acceder desde una aplicación web (Angular) o desde un dispositivo móvil.

Explicación:

El usuario interactúa con el sistema mediante la interfaz web. Todas las solicitudes se envían al API Gateway, evitando el acceso directo a los microservicios.

2. API Gateway (7091)

Es la puerta de entrada de todo el sistema.

Explicación:

El API Gateway centraliza las peticiones, valida los tokens JWT, aplica reglas de seguridad y redirige las solicitudes al microservicio correspondiente.

Ejemplo:

Login → Auth
Consultar productos → Producto
Registrar pedido → Pedido
3. Eureka Server (7081)

Es el registro de servicios.

Explicación:

Eureka permite que los microservicios se descubran automáticamente entre sí. Cuando un servicio inicia, se registra en Eureka para que otros puedan localizarlo sin conocer su dirección física.

4. Config Server (7071)

Gestiona la configuración centralizada.

Explicación:

Todas las configuraciones de los microservicios se almacenan en un repositorio Git. Al iniciar, cada servicio obtiene su configuración desde el Config Server, facilitando la administración y mantenimiento.

5. Microservicio Auth (8042)

Gestiona autenticación y autorización.

Explicación:

Este servicio registra usuarios, realiza el inicio de sesión y genera tokens JWT. Además administra roles como ADMIN y USER.

6. Microservicio Producto (9091)

Gestiona los productos.

Explicación:

Permite registrar, consultar, actualizar y eliminar productos del catálogo de la cafetería.

Ejemplos:

Café Americano
Capuccino
Sandwich
Postres
7. Microservicio Categoría (9090)

Organiza los productos.

Explicación:

Administra las categorías de los productos para facilitar su clasificación.

Ejemplos:

Bebidas
Postres
Snacks
8. Microservicio Pedido (9096)

Administra pedidos.

Explicación:

Recibe los pedidos realizados por los clientes, valida los productos seleccionados y registra la orden correspondiente.

9. Microservicio Pago (6060)

Procesa pagos.

Explicación:

Gestiona el registro y validación de los pagos asociados a los pedidos realizados por los clientes.

10. Microservicio Reporte (9071)

Genera reportes.

Explicación:

Obtiene información de pedidos, productos y pagos para generar estadísticas e informes administrativos.

Ejemplos:

Productos más vendidos.
Ventas diarias.
Ingresos mensuales.
11. Base de Datos

Cada microservicio tiene su propia base de datos.

Explicación:

Siguiendo el principio de independencia de los microservicios, cada servicio administra sus propios datos, reduciendo el acoplamiento y mejorando la escalabilidad.

12. Observabilidad

Incluye Prometheus, Grafana, Loki y Promtail.

Prometheus

Recolecta métricas de todos los microservicios mediante los endpoints /actuator/prometheus.

Grafana

Muestra dashboards para monitorear el estado del sistema, tiempos de respuesta y consumo de recursos.

Loki

Centraliza los logs generados por los microservicios.

Promtail

Recopila los logs y los envía a Loki para su almacenamiento y consulta.
